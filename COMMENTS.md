## Comentários sobre o desenvolvimento / Usos de inteligência artificial

### Dia 1 (24/07/2026)

- Durante o primeiro dia foquei em iniciar algumas revisões e estudos acerca das tecnologias pedidas para o desafio. Fazia algum tempo que não mexia com desenvolvimento web e, por conta disso, precisei fazer uma revisão sobre React. A tecnologia para o backend que eu escolhi foi o TypeScript invés de JavaScript. Apesar de não ter tido contato prévio com a linguagem, achei ser uma oportunidade interessante para aprender um pouco sobre o sistema de tipagem. Fiz também o setup inicial do repositório.

- Uso de IA: O uso de IA foi majoritariamente durante a parte do desenvolvimento de CSS da homepage, principalmente pesquisando e ajustando propriedades visando responsividade e correção de bugs.

### Dia 2 (25/07/2026)

- Estruturei a base do projeto, realizando a separação arquitetural entre backend e frontend. Fiz a implementação da homepage de busca e iniciei a configuração do GraphQL, criando os arquivos de startup e de query da API.

- Uso de IA: Gerei o arquivo JSON que será o banco de dados das sugestões de busca. Além disso, o uso majoritário foi para tirar dúvidas e arrumar possíveis bugs do GraphQL, visto que foi a primeira vez que utilizei a biblioteca.

### Dia 3 (26/07/2026)

- Não continuei o desenvolvimento do projeto pois estava viajando.

### Dia 4 (27/07/2026)

- Retomei o desenvolvimento focando na integração e funcionalidade principal do buscador. Implementei a função de autocomplete e criei o componente de dropdown para exibir as sugestões de pesquisa.

- Uso de IA: Uso majoritário na parte do CSS para fazer o componente de dropdown, corrigindo alguns bugs e ajustes de responsividade, também utilizei IA para corrigir alguns bugs da manipulação dos estados do React durante as pesquisas por parte do usuário.

### Dia 5 (28/07/2026)

- Dia focado em infraestrutura e documentação. Configurei o Docker para conteinerizar a aplicação, integrei CI utilizando o GitHub Actions. Escrevi a documentação do README detalhando a stack e como utilizar o projeto. 

- Uso de IA: Nesse dia o uso foi mais intenso, sendo muito usado como ferramenta de DevOps e debugging. A IA foi essencial para me ajudar a resolver algunsconflitos de volumes do Docker com o Webpack do React. Também utilizei a IA para tirar dúvidas sobre Lint/CI, além de gerar a estrutura do pipeline de CI (ci.yml).
